# Fundamental-search-algorithms-in-programming
Fundamental qidiruv algoritmlari — bu kompyuter xotirasida yoki ma'lumotlar bazasida saqlanayotgan ma'lumotlar orasidan kerakli elementni (qiymatni) eng samarali va mantiqiy yo'l bilan topish uchun mo'ljallangan qoidalar majmuasidir.

№	Qidiruv algoritmi-        	   O‘zbekcha nomi
1	Linear Search             	  - Chiziqli qidiruv
2	Binary Search       	        - Binar qidiruv
3	Jump Search         	        - Sakrab qidiruv
4	Interpolation Search	        - Interpolatsion qidiruv
5	Exponential Search	          - Eksponensial qidiruv
6	Ternary Search	              - Uchlik qidiruv
7	Fibonacci Search	            - Fibonachchi qidiruvi
8	Hash-based Search	            - Xesh orqali qidiruv
9	Depth-First Search (DFS)	    - Chuqurlik bo‘yicha qidiruv
10	Breadth-First Search (BFS)	- Kenglik bo‘yicha qidiruv
11	A* Search	                  - A-yulduz qidiruvi
12	Best-First Search	          - Eng istiqbolli yo‘l bo‘yicha qidiruv
